# סושיאל: תיווך נדל"ן (אני + אבא)

## פרופיל העסק
- **אזור:** השרון, וגם כל הארץ. כל סוגי העסקאות (מכירה, השכרה, מגורים, מסחרי).
- **מטרה:** למכור את הנכסים שבשיווק.
- **ערוצים:**
  - פייסבוק, העמוד של אבא: כ-5,400 עוקבים (הכי גדול)
  - פייסבוק, העמוד שלי: כ-3,200 עוקבים
  - אינסטגרם: נפתח לאחרונה
- **צילום:** אבא מצלם. אף אחד לא מופיע מול המצלמה, ולכן התוכן בלי פנים: סרטוני נכס, כתוביות, קריינות AI.
- **כלים:** Higgsfield לסרטונים מתמונות של נכסים.
- **זמנים:** אין שעה קבועה, מצלמים כשיש נכס.
